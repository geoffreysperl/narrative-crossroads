## Overview

This presentation introduced TTRPG pedagogy to a hobbyist gamer audience, using Basic Roleplaying (BRP) mechanics as the entry point. The focus was on helping gamers understand how their existing skills translate to educational contexts.

### Target Audience

- Hobbyist TTRPG players curious about education applications
- Game masters interested in running games for younger players
- Parents who game and want to connect gaming to learning

### Key Themes

- TTRPGs as literacy environments (not gamification)
- The "magic circle" as a safe space for learning
- How GM skills parallel teaching skills
- BRP mechanics as accessible entry point for educators
